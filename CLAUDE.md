# Проект: «Как жить лучше», версия для России

Владелец: Макс. Общается по-русски, коротко и прямо, на «ты». Не задавай лишних вопросов: работай пачками и отчитывайся результатом.

## Что это

Сайт (один HTML-файл) с советами для жизни, отсортированными по выгоде: сколько стоит (деньги, время, воля), что даёт (жизнь, деньги, время, свобода) и насколько доказано (A/B/C). Основа: китайская книга-руководство **HowToLiveBetter** (eternity4719, лицензия Unlicense), 630 записей, лежит в `source/HowToLiveBetter.html`. Мы **переводим и адаптируем её под Россию**, а не копируем.

Опубликованный сейчас вариант: 284 записи, 11 разделов (см. `docs/translation-manifest.csv`).

## Жёсткие правила (не нарушать)

1. **Числа только из оригинала или из проверенного российского источника.** Ничего не выдумывай, не «округляй по памяти». `tools/mkcontent.py` сверяет числа с оригиналом и печатает `WARN numbers not found in source`: каждое такое предупреждение объясни (округление, выведено из другого числа, российская норма) или исправь.
2. **Россия и только Россия.** Всё, что зависит от страны (законы, суммы, ведомства, телефоны, программы), пишем для России и **проверяем по официальному источнику** (КонсультантПлюс, ГАРАНТ, pravo.gov.ru, сайты ведомств, Банк России, Госуслуги, Минздрав, МЧС). Указываем дату проверки. **Нет подтверждения = не пишем**, убираем запись или часть записи. Никаких китайских законов, ведомств и номеров (12356, 120, 110 и т. п.).
3. **Медицина**: врач проверит всё перед публикацией на GitHub. Не давай доз и схем лечения без источника из оригинала. Рецептурные препараты: «только по назначению врача».
4. **Самоповреждение и суицид**: не пиши способов, средств и исходов. Только защитные советы + номер МЧС (8 (495) 989-50-50, psi.mchs.gov.ru; проверено 29.09.2026). Записи 1.33 и 1.34 намеренно не переносятся.
5. **Деньги и инвестиции**: не инвестиционная рекомендация, так и пиши в конце записи.
6. **Не выдумывать источники.** Ссылки берём из оригинала или находим сами и открываем.
7. Доказательность (A/B/C) берётся из оригинала. Если запись держится только на практическом опыте, честно пиши «Уровень C». Если исследования спорят, ставь `"dispute": true` и объясни спор в `c`.
8. Тон текста: «вы», спокойно, без морализаторства, без «ты должен». Короткие предложения. Без канцелярита.

## Как устроен конвейер

```
source/HowToLiveBetter.html   оригинал (630 записей)
        │  tools/show.py, tools/rd.py — читать оригинал
        ▼
src/in/NN_тема.json           НАШИ русские записи (пачки). Правим только их
        │  tools/mkcontent.py — подтягивает из оригинала теги/уровень/затраты/источники, сверяет числа
        ▼
src/gen.js                    сгенерировано, не править руками (в .gitignore)
        │  tools/build.py — склеивает data.js + core.js + a.txt (шаблон) + gen.js
        ▼
dist/index.html               готовый сайт (можно выкладывать на GitHub Pages)
```

Команды:

```
python3 tools/show.py 7.1 7.2          # оригинал полностью
python3 tools/rd.py 7.1,7.2,7.3        # оригинал сжато (для быстрого чтения пачки)
python3 tools/mkcontent.py             # собрать gen.js, показать WARN
python3 tools/build.py                 # собрать dist/index.html
python3 tests/sweep.py [--quick]       # проверка размеров экрана, тем, ошибок
python3 tools/manifest.py              # пересчитать статусы всех 630 записей
python3 tests/func.py                  # функциональная проверка: подгрузка, фильтры, поиск, запись, тема
python3 tests/layout.py                # отступы и вылезание текста на 11 ширинах экрана
python3 tests/perf.py [--mobile]       # скорость: загрузка, простой, прокрутка (CPU замедлен в 4 раза)
```

Проверка `tests/sweep.py` нужна после **каждой** пачки (`pip install -r requirements.txt && playwright install chromium`). Без чистого результата не считай пачку готовой.

## Формат записи (`src/in/*.json`, массив объектов)

```json
{
 "k": "19.4",                 // ключ записи в оригинале (глава.номер). Из неё берутся теги, A/B/C, затраты
 "id": "layoffpay",           // уникальный латинский id (для ссылки #layoffpay)
 "cat": "work",               // раздел: safety health food mind love family focus work money myths urgent
 "urgent": true,              // только для экстренных инструкций (cat = urgent)
 "dispute": true,             // исследования спорят: покажет метку «Есть спор»
 "t":  "Заголовок-совет одной фразой",
 "p":  ["деньги","время","воля"],   // три короткие строки «сколько стоит»: на что уходит
 "b":  "2 месяца",            // большое число на карточке (короткое: до ~9 знаков, иначе шрифт уменьшится)
 "bl": "что это за число",
 "d":  "Что делать (1-2 предложения)",
 "st": ["шаг 1","шаг 2"],     // пошаговая инструкция (обязательна у urgent)
 "stt": "Заголовок списка шагов",   // необязательно
 "n":  ["абзац с цифрами и выводами из источников"],   // вкладка «Что показали исследования»
 "c":  "Что важно учесть: спор, ограничения, уровень доказательств",
 "o":  "Наше добавление (необязательно)",
 "lr": {"text":"...","checked":"дд.мм.гггг","src":[["название","https://..."]]},  // вкладка «В России»
 "lk": "emergency",           // подставит блок с номерами 112/103
 "src": [["название источника","https://..."]]   // переопределяет источники оригинала (ОБЯЗАТЕЛЬНО для российских норм; [] = без источников)
}
```

Правила полей: `{HR}`, `{RR}`, `{OR}`, `{CI}` в тексте превращаются в подсказки-аббревиатуры. Вкладка «В России» появляется, только если есть `lr` или `lk`; пустых заглушек не делаем.

Для российской нормы (закон, статья, сумма) сначала найди и открой источник, потом пиши. Ссылки оформляй в `src` с названием документа и статьёй. Эталон: записи `overtimepay`, `wagedelay`, `layoffpay`, `vacation28`, `legalaid`, `jobreg`, `medrecords`, `emergencyfree` в `src/in/24_labor_ru.json` и `25_rescued_b.json`.

## Что где лежит

- `src/data.js` разделы (`CATS`, `CAT_ORDER`), справочник, 26 «старых» записей (без поля ch), блок `LOCAL.emergency`. Маркер `/*@@GEN@@*/` вставляет `gen.js`.
- `src/core.js` движок: сортировка, фильтры, состояние (сделано/сохранено), вкладки записи.
- `src/a.txt` шаблон дизайна (HEAD/CSS/HTML/JS) и эффекты (`a_fx.js` встроен в JS): ночная тема, консоль фильтров, карточки, ящик записи, «Созвездие» и финал.
- `src/a_fx.js` эффекты полёта частиц, круговая смена темы, «Созвездие». Хранится отдельно, но вставляется в `a.txt` вручную (при правке `a_fx.js` его текст надо скопировать в блок «ЭФФЕКТЫ» шаблона `a.txt`, между заголовком «ЭФФЕКТЫ» и блоком «первый экран»).
- `tools/triage.json` решения по записям: что убрано как «только Китай», что отложено, карта старых записей, тема России для каждой главы.
- `docs/translation-manifest.csv` статус каждой из 630 записей (генерируется).

Добавить новый раздел: `CATS` и `CAT_ORDER` в `data.js`, иконка в `P` в `core.js`, иконка-маска `#c-<cat>+label` и карта `CI` в `a.txt`. Образец: раздел `work` («Работа и права»).

## Производительность (не ломать)

Замеры при замедлении CPU в 4 раза: загрузка 7,5 с → 1,1 с, простой 28 → 57 кадров/с, прокрутка 15 → 46. Правила, которые это держат:

- Список рисуется порциями (`CHUNK=24` в `renderList`, подгрузка по `IntersectionObserver`), а не весь сразу: всего ~470 карточек дают ~20 тысяч DOM-узлов. Новые порции, которые подгружает прокрутка, не анимируются.
- Анимация появления карточек только у первых 9, не более 8 за раз. Любая анимация элемента каждый кадр дёргает пересчёт стилей: не вешать бесконечные анимации на десятки элементов.
- Небо: звёзды мерцают через `opacity` с числами без `var()` в keyframes, фон звёзд задан `color-mix`. Анимации неба ставятся на паузу, когда небо ушло с экрана или открыта запись (`.sky.rest`, `.lock`).
- Никакого `filter: blur()` на анимируемых слоях (полосу неба растушёвывает статичная маска). Параллакс неба задаётся прямым `transform`, а не CSS-переменной на предке: переменная заставляет пересчитать стили всех потомков.
- Размеры читать пачкой, потом писать (`thumbs`), вызовы `update()` объединены через `requestAnimationFrame`.
- Перед push: `mkcontent.py` → `build.py` → `tests/sweep.py` → `tests/func.py` → `tests/layout.py` → `tests/perf.py`.

## Как вести пачку

1. Тема из очереди (`/next-batch <тема>`).
2. Читаешь оригиналы, ищешь российские источники (WebSearch/WebFetch), проверяешь каждое число.
3. Пишешь `src/in/NN_….json` (следующий свободный номер), 12–25 записей за раз. Не пиши запись, для которой нет источника.
4. `mkcontent.py` → разбор WARN → `build.py` → `tests/sweep.py` → `manifest.py`.
5. Короткий отчёт Максу: что добавлено, что отложено и почему, сколько осталось по теме. Обновляй раздел «Текущее состояние» этого файла, если поменялись цифры.
