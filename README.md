# Как жить лучше (версия для России)

Сайт с советами для жизни в порядке выгоды: сколько стоит (деньги, время, сила воли), что даёт (жизнь, деньги, время, свобода) и насколько доказано (уровни A, B, C). Каждая запись написана «простым языком», с цифрами из исследований и со ссылками на источники.

**Сайт: https://maxbzd.github.io/HowToLiveBetter/** (репозиторий: https://github.com/maxbzd/HowToLiveBetter).

Сайт — один файл `dist/index.html`. Он открывается без сервера, внешние только шрифты Google Fonts.

## Откуда это

Основа — китайская книга-руководство [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) («高性价比人生指南»), автор eternity4719, лицензия [Unlicense](https://unlicense.org/) (общественное достояние). Мы не копируем её, а переводим и адаптируем под Россию:

- всё, что зависит от страны (законы, суммы, ведомства, телефоны, программы), заменено российским или убрано;
- российские нормы проверены по КонсультантПлюс, ГАРАНТ, Банку России и сайтам ведомств, дата проверки указана в записи (вкладка «В России»);
- записи, у которых нет российского аналога, в сайт не вошли;
- уровень доказательности (A, B, C) взят из оригинала, спорные записи помечены.

Что вошло и что нет, видно в [`docs/translation-manifest.csv`](docs/translation-manifest.csv): статус каждой из 630 записей оригинала. Причины для непереведённых записей лежат в `tools/triage.json`.

## Важно

- **Это не медицинская и не юридическая консультация.** Записи рассказывают, что известно, и не заменяют врача или юриста.
- В записях о лекарствах нет доз. Рецептурные препараты принимают только по назначению врача.
- Законы меняются. Перед действием проверьте актуальную редакцию по ссылке в записи.
- Если вам плохо или вы думаете о том, чтобы навредить себе: психологическая помощь МЧС 8 (495) 989-50-50, экстренные службы 112.

## Проверка перед публикацией

Список записей, которые должны посмотреть врач и юрист: [`docs/review-checklist.md`](docs/review-checklist.md). Он собирается командой `python3 tools/review_list.py`.

## Запуск

```
python3 tools/mkcontent.py   # собрать записи из src/in/*.json в src/gen.js
python3 tools/build.py       # собрать dist/index.html
```

Затем откройте `dist/index.html` в браузере.

Проверка: `pip install -r requirements.txt && playwright install chromium`, затем `python3 tests/sweep.py` (экраны и темы), `python3 tests/func.py` (работа сайта), `python3 tests/layout.py` (отступы), `python3 tests/perf.py` (скорость).

## Публикация на GitHub Pages

GitHub Pages умеет отдавать только корень репозитория или папку `/docs`, а наш сайт лежит в `dist/`. Поэтому в репозитории есть готовый workflow `.github/workflows/pages.yml`, который публикует папку `dist`.

1. Выложите проект в репозиторий на GitHub (вместе с готовым `dist/index.html`).
2. Settings → Pages → Source: **GitHub Actions**.
3. После каждого push в `main` сайт обновляется сам: https://maxbzd.github.io/HowToLiveBetter/. Если первый запуск упал до включения Pages, откройте вкладку Actions и нажмите Re-run jobs.

## Как устроен проект

```
source/HowToLiveBetter.html   оригинал (630 записей)
src/in/NN_тема.json           наши русские записи (правим только их)
tools/mkcontent.py            собирает gen.js, сверяет числа с оригиналом
tools/build.py                склеивает всё в dist/index.html
tests/sweep.py                проверка размеров экрана, тем и ошибок JS
tools/manifest.py             статус каждой из 630 записей
```

Подробные правила и формат записи: [`CLAUDE.md`](CLAUDE.md). Для работы с Claude Code откройте папку проекта и запустите `claude`.
